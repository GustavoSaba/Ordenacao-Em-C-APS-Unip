**Atividade para a faculdade, onde devemos implementar um algoritmo em C que realize e apresente testes de ordenação de dados com os seguintes tipos:**

1. *Diversos Tamanhos:*
   1. 1000
    2. 5000
    3. 10000
    4. 100000
  2. *Com e Sem Duplicidade*
3. *Diferentes Disposições:*
    1. Ordem Crescente
    2. Ordem Decrescente
    3. Aleatória
    4. Côncava
    5. Convexa

Os resultados obtidos dessas ordenações vão ser apresentados por meio de tabelas e gráficos.

Iremos utilizar três metódos de estrutura de dados para esta ordenação, segundo o que foi pedido na atividade, sendo estes:
1. Bubble Sort
2. Merge Sort
3. Quick Sort

**O objetivo desta pesquisa é identificar as vantagens e desvantagens de cada algoritmo, em todos os cenários.**
